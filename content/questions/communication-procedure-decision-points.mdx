prompt: >-
  A written procedure is better if it leaves out the awkward cases, so that the
  person following it can use their own judgement.
answer: false
explanation: >-
  The awkward cases are the part that makes a procedure useful. Every process has
  places where a real person gets stuck — a file with no clear date, two clients
  with the same name — and if the procedure does not say what to do, it gets
  abandoned the first time one of them happens. Judgement is needed for the cases
  nobody anticipated, not for the ones you already know about.
