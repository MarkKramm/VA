type: single-choice
prompt: >-
  You need the client to choose how a folder should be set up. Which message is
  most likely to get a fast, useful answer?
choices:
  - id: open-question
    text: How would you like the folder set up?
  - id: options
    text: >-
      Should I use the existing structure or create a new one? Existing / new —
      either works, I just need to know which.
  - id: permission
    text: Is it okay if I reorganise the folder?
  - id: defer
    text: Let me know when you have time to discuss the folder.
correctChoiceId: options
explanation: >-
  A question with options can be answered with one word. An open question makes
  the client think about a problem you have already thought about, and asking for
  permission invites a "no" without offering a path forward.
