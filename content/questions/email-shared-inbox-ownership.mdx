type: single-choice
prompt: >-
  In a shared inbox, what should every message have before you move on to the
  next one?
choices:
  - id: a-label
    text: A label matching the client or project
  - id: an-owner-and-status
    text: An owner and a status
  - id: a-star
    text: A star so it can be found later
  - id: a-reply
    text: A reply, even if it only acknowledges receipt
correctChoiceId: an-owner-and-status
explanation: >-
  The failure mode of a shared inbox is a message four people read, three assumed
  someone else would answer, and nobody did. An owner and a status make that
  impossible: an unassigned message in a shared inbox is nobody's. Labels help you
  find things; they do not tell the team who owes an answer.
