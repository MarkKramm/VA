prompt: >-
  Once you have identified duplicate rows in a client's dataset, you should delete
  the extras so the file is clean.
answer: false
explanation: >-
  Two rows can look identical and still be two real things — two people with the
  same name, two invoices for the same amount, two orders placed minutes apart.
  The professional move is to mark them in a separate column with a note and let
  the client decide. Deleting a row that turned out to be a separate order is not
  recoverable with an apology.
