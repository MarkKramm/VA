#### Set it up

Use a drive you have access to — your own is fine if you have no client drive yet.
If you have neither, invent a realistic one on paper: six top-level folders, mixed
naming, one folder shared with an outside address.

#### What to produce

```text
Drive:            <name>
Surveyed by:      <your name>, <date>

Top-level folders
  Clients/        one folder per client, named Firstname Lastname
  Templates/      letterheads, invoice template, one slide deck
  _Inbox/         unfiled, no convention visible
  …

Naming pattern
  Client folders:  "Acme Co" — no dates, no codes
  Documents:       mixed — some YYYY-MM-DD, some free text

Sharing
  Clients/Acme Co   — shared with accounts@… (can edit)
  _Inbox            — anyone with the link (can view)

Questions before I change anything
  1. …
```

#### How it will be judged

- **You read before you wrote.** Nothing moved, renamed or deleted. The exercise
  is a survey, and the temptation to tidy is the thing being tested.
- **The sharing level is recorded with its exact name.** "Shared" is not a
  setting; "anyone with the link" is.
- **You found the folder with no convention.** `_Inbox` is where the drive's
  author gave up, and it is usually where the real problem is.
- **The questions are specific.** "Can I reorganise the drive?" invites a no.
  "Would it help if I filed \_Inbox into the client folders using the existing
  naming?" invites an answer.
