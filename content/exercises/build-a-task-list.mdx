#### The brief

> "Hi — hope you had a good weekend. A few things this week if you get a chance.
> The shared drive is a mess again, so can you sort that out. Also I need to send
> Priya the March numbers but I've lost track of which version is right — can you
> work out which one and send it? And we should probably update the invoice
> template to the new logo. Oh, and can you check whether we've paid the hosting
> invoice, I have a feeling it's overdue. Don't worry about the newsletter this
> week, we're skipping it. Thanks!"

#### What to produce

**1. The task list.** Number every action. Some of them need splitting into
sub-steps.

**2. The gaps table.** For each task, the who / what / where / when you cannot
answer:

| Task                     | Missing                                         |
| ------------------------ | ----------------------------------------------- |
| 1. Tidy the shared drive | Which drive, and what counts as tidy this time? |
| 2. …                     | …                                               |

**3. One message to the client** containing every question, in the same order as
the task list.

#### How it will be judged

- **Six actions, not one paragraph.** The brief contains: tidy the drive, find the
  right March numbers and send them, update the invoice template, check the
  hosting invoice, and the instruction _not_ to do the newsletter. That last one
  is information, not a task — recognising the difference is part of the exercise.
- **"Which version is right" is the hard task**, and it needs a rule, not a guess.
  Say what you would check.
- **"I have a feeling it's overdue"** is not a deadline. Your question should
  establish one.
- **One message.** Four separate messages across a day is the failure this exercise
  is designed to catch.
